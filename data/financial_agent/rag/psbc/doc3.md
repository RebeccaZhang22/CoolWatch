# 基金定投

基金定投是定期定额投资基金的简称，是指在固定的时间以固定的金额投资到指定的开放式基金中。我行为投资者提供基金定投服务。

一、产品特色

（一）方式灵活多样

我行基金定投功能为投资者提供多种扣款选择，投资者可以自主选择所投基金、扣款日期、定投金额、扣款频率（按日、按周、按月），我行还为投资者提供补扣款服务，以更好地满足投资者的个性化需求。

（二）摊薄成本，分散风险

基金定投具有投资资金分期投入，摊薄成本，分散市场波动风险的特点。

（三）小额投资，更易坚持

基金定投无需一次性投入大笔资金, 分散投资更容易长期坚持，可以达到积少成多，聚沙成塔的效果。

（四）精挑细选，组合推荐

我行为投资者精心挑选国内优秀公司的绩优基金，立足于基金中长期业绩和基金经理的长期投资经历，从投资者理财需求和中长期资产配置出发，致力于为投资者提供养老、教育、置业等专业化的家庭理财解决方案。

二、服务特色

止盈定投业务（U定投）

投资者可通过我行手机银行自主开通止盈定投业务（U定投）。业务开通后，投资者可自主对基金收益率设定止盈目标，发起对约定基金产品的定时定额申购（以下简称“定投”）。一旦达到目标收益，系统自动触发赎，并在下一个定投扣款日期自动开启续投。U定投解决了投资者何时卖出基金的困惑，止盈不止投的设计也让投资者省心又省力。

三、业务流程

投资者需携带本人有效身份证件和邮储银行借记卡到我行营业网点或通过网上银行、手机银行自助办理基金定投业务。具体业务办理流程，详询理财经理或拨打95580 咨询。

四、收费须知

投资者通过我行渠道进行基金交易需承担一定的手续费用，收费标准请以基金管理公司披露的法律文件或我行公告为准。

五、温馨提示

投资者可设置定投最低起点金额以基金公司为准。

投资者可以同时办理多只基金的定投业务，在办理基金定投业务前需进行风险测评，所投产品需匹配风险评级。

邮储银行代销的基金产品由基金管理人发行与管理，邮储银行不承担基金产品的投资、兑付和风险管理责任。基金有风险，投资需谨慎。

投资人应当充分了解基金定期定额投资和零存整取等储蓄方式的区别。定期定额投资是引导投资人进行长期投资、平均投资成本的一种简单易行的投资方式。但是定期定额投资并不能规避基金投资所固有的风险，不能保证投资人获得收益，也不是替代储蓄的等效理财方式。
