# 对标市场的指数型基金

在投资市场中，有一类基金因“省心、透明、低成本”成为被广泛关注的选择，它就是指数型基金。不同于主动管理型基金依赖基金经理选股决策，指数型基金更像“跟着市场走”的标准化投资产品。

要理解指数型基金，得先明白“指数”是什么。指数是按照某种规则选取的一揽子股票集合，它反映了这一揽子股票所代表的某一股票市场的涨跌趋势特征。比如沪深300指数挑选了A股市场300只优质大盘股，能反映整体市场的大致走势；而白酒指数、金融地产指数则聚焦特定行业，反映行业的整体表现。

举个生活化的例子：判断一个班级的数学平均水平，我们把全班同学的数学成绩相加求平均数，这个平均数就是“班级数学成绩指数”，它的变化能直接反映班级整体数学水平的波动。股市里的指数，本质上就是市场或板块的“平均成绩”。

指数型基金就是追踪某种指数的基金产品，它以该指数的成分股为投资对象，通过购买指数的全部或者部分成分股来构建投资组合。因为指数型基金持有股票的种类、数量、比例都与指数十分接近，所以指数型基金的表现也与指数非常接近。换句话来说，指数型基金把指数这个抽象的概念变成了可以实际交易的产品，比如买了中证500指数基金，就相当于间接持有了沪深两市500只中小盘股。

根据不同的划分标准，指数型基金主要分为两种类型：

根据是否限定投资行业，指数型基金分为宽基指数型基金和窄基指数型基金。宽基指数基金跟踪的指数成分股数量多、覆盖面广，横跨多个行业，能反映整体市场走势，A股中常见的宽基指数有沪深300指数、创业板指数、上证50指数、深证100指数、中证500指数等。这类基金风险相对分散，适合追求市场平均收益的长期投资。窄基指数基金就是那些集中投资的特定的一些策略类、风格类、行业类、主题类的相关指数，并进一步划分为行业指数型基金、主题指数型基金、策略指数型基金。这类基金波动相对较大，但如果踩中热门行业，可能获得高于市场平均的收益，适合对特定领域有了解的投资者。

按交易方式不同，指数型基金分为场内指数型基金和场外指数型基金。场内指数型基金就是在交易所内上市交易的指数型基金，需要投资者在证券公司开户，使用交易软件交易，申购赎回。场外指数型基金不能在交易所直接买卖，需要通过证券公司，基金公司，银行柜台等销售平台申购赎回。

指数型基金之所以被广泛关注，与其自身的特点密切相关。一是收益表现与目标市场平均水平贴合，不会出现因个股选择失误导致的极端偏差；二是日常价格波动幅度，远低于绝大多数个股；三是不存在个股停盘无法交易的情况；四是不断优胜劣汰（由于指数不断根据市值、成交量等指标调入代表性股票，会根据市场指标择优选择）；五是运作成本相对较低，市场上大部分指数型基金的管理费率比股票型基金低一半甚至一半以上。

作为投资市场中一类标准化、透明化的产品，指数型基金以独特的跟踪机制，成为连接普通投资者与资本市场的重要载体，其稳定的运作模式和广泛的市场覆盖性，能够有效丰富资本市场产品供给、完善市场结构，为资本市场的平稳健康发展提供支撑。
