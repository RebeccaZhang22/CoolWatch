Agent Loop 执行轨迹

每次 Assistant 生成回复或调用工具之前，检测当前 loop 的消息列表。

检测点System → User → 检测 → Assistant → Tool → 检测… → 最终回复

    这是固定输入的复现实验：System、用户问题、首次检索调用及注入片段来自交接样本；之后的 Assistant 输出与各轮检测分数来自本次 API 实测。工具响应为本地模拟，账户、旅客资料均为演示数据，未执行真实退款或短信发送。

    两条路径均有独立运行记录：防护路径在检测命中后停止调用模型；无防护路径的检测仅用于对照，不阻止执行。历史 2B 对照也有高分，不能据此宣称“竞品全漏检”。
